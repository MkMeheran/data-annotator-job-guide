# Mercor Data Annotation Test: My Experience

This is what the Mercor assessment for a data annotator role looked like for me. I do not share the real passage, strings or my answers. I only describe the tasks.

## The basics

- The test has 3 sections.
- There is no time limit, but your completion time is recorded.
- The page says quality matters most, so the goal is correct answers in a short time.
- Using AI is prohibited and can lead to automatic disqualification.
- At the end there is a feedback page. It also asks if you allow them to share your answers anonymously to train future candidates.

## Section 1: text

You read one short passage about a work protocol. Then you answer five counting questions and write a summary.

- Words that start with a vowel and are longer than 5 letters
- Numbers whose digits add up to a given value
- Words with double letters
- Words that end in certain letters
- Words that name a unit of time
- Summary in 150 words or less, "precise and thorough"

Every counting question says to include the title.

## Section 2: strings

- 7 pairs of letter strings. You mark each pair SAME or DIFFERENT.
- 3 long master strings. You choose the matching option in a dropdown.

## Section 3: images

- 7 image sets. Each has a main image and six options, A to F.
- You tick every option that matches the main image.

## How it went

After I submitted, I checked my work. I found mistakes in the counting questions, in one string pair and in the summary. The details are in [mistakes-and-lessons.md](mistakes-and-lessons.md).

## Main lessons

- The test checks care, not intelligence. It is about following rules when the task is boring.
- Counting by eye does not work. Use a clear method and check twice.
- The summary needs correct meaning, correct numbers, nothing added, and a word count check.
